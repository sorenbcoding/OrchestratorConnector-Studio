# Orchestrator Connector for UiPath Studio

A UiPath Studio extension for switching the local Studio and Robot between Orchestrator tenants with saved presets. Each preset holds a name, an Orchestrator URL, a machine client ID and a client secret.

This is the in-Studio version of the [Orchestrator Connector](https://github.com/sorenbcoding/OrchestratorConnector) desktop app. Both use the same preset store.
